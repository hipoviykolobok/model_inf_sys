# Моделирование приёмки и размещения палет на складе

Практическая работа 1 по дисциплине «Модели информационных процессов и систем». Репозиторий содержит постановку задачи моделирования, описание системы, схему процесса и ментальную карту.

## Задача

Неравномерное поступление палет вызывает очереди на приёмке и размещении. Требуется сравнить организацию работы шести специализированных сотрудников, закреплённых за участками, и шести универсальных сотрудников, перераспределяемых в зависимости от очередей.

Для специалистов рассматриваются распределения «приёмка / размещение» 2/4, 3/3 и 4/2. Возможное преимущество специалистов в скорости является гипотезой, а не установленным фактом. Сценарии сравниваются при одинаковых поступлениях и графике работы.

Показатели результата:

- среднее полное время обработки палеты;
- максимальная суммарная очередь за смену;
- число палет, не размещённых к концу смены.
