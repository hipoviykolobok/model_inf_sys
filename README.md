# Моделирование приёмки и размещения палет на складе

Практическая работа 1 по дисциплине «Модели информационных процессов и систем». Репозиторий содержит постановку задачи моделирования, описание системы, схему процесса и ментальную карту.

## Задача

Неравномерное поступление палет вызывает очереди на приёмке и размещении. Требуется сравнить организацию работы шести специализированных сотрудников, закреплённых за участками, и шести универсальных сотрудников, перераспределяемых в зависимости от очередей.

Для специалистов рассматриваются распределения «приёмка / размещение» 2/4, 3/3 и 4/2. Возможное преимущество специалистов в скорости является гипотезой, а не установленным фактом. Сценарии сравниваются при одинаковых поступлениях и графике работы.

Показатели результата:

- среднее полное время обработки палеты;
- максимальная суммарная очередь за смену;
- число палет, не размещённых к концу смены.

## Статус работы

Подготовлена постановка задачи: проблема, заинтересованные стороны, альтернативы, исследовательский вопрос, границы, схема, словарь величин, KPI, допущения, варианты модели, план проверки и ограничения.

Программная реализация и численные эксперименты пока не выполнены. Реальные журналы склада отсутствуют, поэтому превосходство какого-либо сценария не подтверждено. Порог перевода работников и длительности операций предстоит определить для экспериментов. Рецензирование работы другого студента выполняется отдельно.

Точная пагинация Word пока не проверена: автоматический рендеринг в рабочей среде недоступен. Основной текст и приложения следует просмотреть в Word перед сдачей.

## Публикация репозитория

Создайте пустой репозиторий на GitHub или GitVerse без автоматически создаваемых README, лицензии и `.gitignore`. В терминале из корневой папки этого проекта выполните:

```powershell
git status
git commit -m "Добавить постановку задачи моделирования склада"
git branch -M main
git remote add origin URL_ВАШЕГО_РЕПОЗИТОРИЯ
git push -u origin main
```

Замените `URL_ВАШЕГО_РЕПОЗИТОРИЯ` фактическим адресом. Материалы подготовлены в индексе Git для первого коммита. Если вы изменили их после подготовки, перед коммитом выполните `git add README.md .gitignore .gitattributes docs images assignment`.

Если Git запросит имя и почту автора, настройте их локально для этого проекта, указав собственные данные:

```powershell
git config user.name "Ваше имя"
git config user.email "Ваша почта или адрес noreply"
```

После настройки повторите коммит. Удалённый адрес, автор и публикация автоматически не настраивались.
